JAYA - Build APK (Android 13 / Redmi Note 11 Pro 5G)

1) pip install buildozer
2) buildozer android debug
3) APK كاين في bin/jaya-0.1.0-debug.apk

ملاحظات:
- البناء كيحتاج Linux/WSL ولا GitHub Actions (buildozer ما كيخدمش مباشرة على Windows).
- permissions: RECORD_AUDIO, INTERNET, WAKE_LOCK
- المفاتيح (Groq / NVIDIA / Google / OpenRouter / Z.ai) كيتخزنو مشفرين محليا فقط، ما كاينش حتى مفتاح فالكود.
